# Lakshmipriya R — DevOps / Cloud Portfolio

A recruiter-focused portfolio for DevOps, SRE and Platform Engineering applications.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```
